## MODIFIED Requirements

### Requirement: Section Navigation Links
The navigation header SHALL provide a link to every major homepage section: Home, Professional Highlights, Professional Experience, Skills, Education, Certifications, and Contact. The navigation header SHALL also provide a link to the Articles section.

#### Scenario: Visitor views the navigation header
- **WHEN** a visitor views the navigation header
- **THEN** a link is present for each of the seven major homepage sections and a link is present for the Articles section

#### Scenario: Visitor activates the Articles link
- **WHEN** a visitor clicks or activates the Articles link in the navigation header
- **THEN** the visitor is taken to the articles listing page
